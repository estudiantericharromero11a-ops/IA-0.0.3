🎯 PRIMEROS PASOS (Elige uno):

OPCIÓN A - INSTALACIÓN AUTOMÁTICA (Recomendado):
  1. Edita .env con tus credenciales PostgreSQL
  2. Ejecuta: python scripts/install_thania.py
  3. Verifica:  python scripts/verify_versions.py
  4. Inicia:    python app.py --local

OPCIÓN B - INSTALACIÓN MANUAL:
  1. pip install -r requirements.txt
  2. python scripts/setup_db.py
  3. python scripts/poblar_datos_ejemplo.py
  4. ollama serve (en terminal separada)
  5. python app.py --local
